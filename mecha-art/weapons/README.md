## 這是什麼遊戲、這些圖用在哪

俯視角機甲射擊遊戲，給小學中年級的小朋友玩。打倒敵人會掉武器，撿起來機甲就換成那把武器。武器圖用在三個地方：
1. **地上掉落**：武器浮在發光底座上（底座、光柱由程式畫）。
2. **選武器卡片**：卡片上的武器大圖。
3. **近戰武器拿在機甲手上**：巨劍、雙刀、長槍、鐵鎚、鎖鏈刃揮砍時，程式把你畫的武器旋轉後畫在機甲手上。

現在是程式畫的（`ref/now-icons.jpg`、`ref/now-melee-in-hand.jpg`），**不夠精緻，請畫得更精緻、更有份量**。造型可以參考現在的樣子，但不用照抄。
參考畫風：`ref/style-game.jpg`（遊戲畫面）。

## 稀有度造型（每把 3 種）

每把武器畫 **3 種造型**，放在同一張圖，由左到右：
1. **基本型**（普通、稀有用）：乾淨的量產款，金屬灰白為主，武器的主色（下表）只出現在少數發光線條。
2. **強化型**（史詩用）：同一把武器升級後的樣子，輪廓一眼看得出更強：**更大、多了裝甲片和尖角、能量核心更亮、發光紋路更多**。不要只是換顏色。
3. **傳說型**（傳說用）：要**最特別、最華麗**，像神器，不只是強化型再加大：
   - 造型大改：加上有生命感的元素（例如龍角、翅膀、星辰、水晶），或是浮在武器旁邊、沒有連在一起的碎片和光環。
   - 金色和白金鑲邊、刻滿發光符文，能量核心變成一顆發光的寶石或小星星。
   - 能量部分用**半透明的漸層光**（像玻璃或光做的），四周有一圈淡淡的光暈和小光點。
   - 小朋友看到要覺得「哇，這把好稀有」。

稀有度的顏色（白、藍、紫、金）由程式在底座和光暈加上去，你不用畫稀有度的顏色。

## 交圖格式（每張都一樣）

1. 一張圖 = 一把武器的 3 種造型，**橫向 3 格**（左：基本型、中：強化型、右：傳說型），整張大約 3:1。大小不限，交原始大圖。
2. **擺法：武器水平放、朝右**：握把在左邊、刀尖／槍頭／鎚頭在右邊，像放在桌上從正上方往下看（輕微立體感可以）。遠程武器（砲、拳頭等）也是水平朝右，砲口朝右。三格的武器擺法、位置一致（傳說型可以比較大）。
3. **背景純黑 `#000000`**，整片均勻，不要地面、影子、手、角色、文字。武器本身最深的地方用深灰、深藍，不要純黑。
4. 武器不能碰到格子邊緣或被切到，四周留一點空白。
5. 畫風：寫實厚塗、金屬質感、明暗清楚、能量部分發光、細節多（鉚釘、刻痕、散熱孔、能量紋路），像高品質手機遊戲的武器圖示。**不要線稿、不要卡通、不要像素。**
6. 不要劍氣、刀光、殘影這類「揮出去的特效」，只畫武器本體（特效由程式畫）。
7. 檔名：`mecha-art/weapons/images/代號__arm.png`。
